Usage notes

Live text — the SVG <text> element loads Inter from Google Fonts. The wordmark renders correctly in any browser with network access. For fully portable use (print, Canva, offline), convert text to outlines in Figma (Object › Flatten) or Illustrator (Type › Create Outlines). The swash is already a <path> — only the letterforms need outlining.
