# Milestone 3: Desktop "Control Room" Dispatch

## Goals
- Empower admins to manage complex scheduling.
- Monitor operational health across the platform.

## Deliverables
- [ ] Desktop-optimized Admin Dashboard (Bento-style).
- [ ] FullCalendar integration with resource view (cleaners).
- [ ] Drag-and-drop task assignment.
- [ ] Inventory tracking based on cleaning task completion.
- [ ] Basic analytics (Efficiency, Completion Rates).

## Success Criteria
- **Efficiency**: Admin can assign 10 tasks to 3 cleaners in under 30 seconds via drag-and-drop.
- **Visibility**: Admin can see any "Late" or "In-Progress" cleans in real-time.
- **Proactive**: System flags "Low Stock" for properties before the next scheduled clean.
