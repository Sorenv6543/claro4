# Milestone 2: Mobile "Proof of Clean" Engine

## Goals
- Operationalize the cleaning process.
- Provide verifiable status updates to owners.

## Deliverables
- [ ] Mobile-first PWA interface for Cleaners.
- [ ] Task generation logic (Check-out = Task Start).
- [ ] Dynamic checklists (Bathroom, Kitchen, Bedrooms, etc.).
- [ ] Image upload and optimization service.
- [ ] Owner "Status" dashboard with photo gallery.

## Success Criteria
- **Operational**: Cleaners can complete a turnover using only their mobile device.
- **Verification**: Every completed task includes a timestamped photo of a critical area (e.g., made bed).
- **Communication**: Owner receives a real-time notification when a clean is finalized.
